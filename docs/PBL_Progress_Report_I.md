| Field | Details |

| **1. Problem Statement / Project Title** | **Student Academic Performance Analytics System – A Java-Based Academic Performance Analytics and At-Risk Student Identification Solution.**<br><br>Universities often face fragmented and manual academic tracking of students, making it difficult to get a clear and complete view of their progress. Identifying students who are struggling early is challenging due to the lack of real-time analysis and consolidated data. There is a need for an automated system that can collect, analyze and visualize academic data to provide better insights and support timely interventions for at-risk students. This project aims to design and develop a Java-based analytics platform that can track student performance, identify risk factors and help educators take informed decisions. |
| **2. Problem Context & Background** | Universities generate a large amount of student data including marks/grades, attendance, assessments, subject-wise performance and semester records. This data is usually stored in multiple systems or spreadsheets, which makes it difficult to get a unified view of each student's progress. Manual tracking is time-consuming, error-prone and does not provide meaningful insights. There is a clear need for a centralized, Java-based analytics platform that can integrate and analyze this data, visualize trends and help in identifying students who may be at academic risk, so that timely support and guidance can be provided. |
| **3. Problem Identification / Understanding** | The core problem is the inefficient monitoring of student performance and the delayed identification of at-risk students. The system will analyze various performance indicators such as grades, attendance and assessment results to provide useful insights and help stakeholders take appropriate action. |
| **4. Objectives** | • Track and analyze student academic performance.<br>• Identify students at academic risk at an early stage.<br>• Generate meaningful performance insights and reports.<br>• Provide a user-friendly system using object-oriented Java concepts. |
| **5. Target Users / Stakeholders** | University administration, faculty members, academic advisors, department heads and students. |
| **6. Research / Literature Review Completed** | Studied existing student performance analytics systems, academic risk prediction approaches, data analysis methods, Java object-oriented design concepts and educational technology practices. |
| **7. Unit/Module Concepts Identified for Application** | The project applies key concepts from Unit 1 and Unit 2 of the syllabus.<br><br>**Unit 1, Object Oriented Programming with Java**, includes classes and objects, inheritance, polymorphism, encapsulation, abstraction, interfaces, exception handling and file I/O.<br><br>**Unit 2, Advanced Java**, includes collections framework, generics, multithreading, JDBC and database connectivity, GUI programming and JavaFX.<br><br>These concepts support the design of a modular, scalable and efficient analytics system with proper data handling, object-oriented structure and database integration. |
